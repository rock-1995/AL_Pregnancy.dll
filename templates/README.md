# Body templates

`base.png` and `reference.png` are the author-selected pair from the installed plugin. The release archive places them beside `AL_Pregnancy.dll`; local builds copy them there automatically.

The plugin adds the reference-minus-base body difference to each character's own original body. See the main README for progress, supported properties, and F1 limits. These template cards are not replacement outfits or faces.

To customize the target, create a valid female AmanatsuLocation base card, edit a copy's desired body properties in the creator, and save it as the reference. Keep unrelated properties identical. Ordinary PNG screenshots lack character data.

Missing/unreadable cards disable only template-based body changes; belly deformation continues.
