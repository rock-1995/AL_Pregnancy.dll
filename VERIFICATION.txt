The cache and classification suites extract the relevant methods from the current production source at build time. Their generated source is not committed. Classification fixtures contain names/paths only, not game geometry. Legacy suites were adapted to the current appearance API and event-driven lifecycle without changing production code or dropping coverage.

These are managed tests and modeled Unity/IL2CPP/Obi boundaries. They do not measure native GPU readback, the actual physics solver, full scene behavior, every pose/outfit, or game FPS. Collision Plus's sphere/capsule contact envelope differs from the previous triangle-based solver. No numerical frame-rate improvement is claimed.

The native collision bridge refreshes only existing belly input data. The production fluid mesh submission and Obi refresh paths remain intact. Character appearance persists in companion-save format v4; version 0.2.44 cannot read a v4 companion, so downgrading requires a compatible native-save/sidecar backup pair.
